# 🚗 Linear and Polynomial Regression Using the Auto MPG Dataset

This project demonstrates **Linear Regression** and **Polynomial Regression** using the **Auto MPG dataset**. The models predict a vehicle's **Miles Per Gallon (MPG)** based on its **engine displacement**.

## 📌 Overview

- Clean and prepare the Auto MPG dataset
- Use `displacement` as the input feature
- Use `mpg` as the target variable
- Train a Linear Regression model
- Train Polynomial Regression models with degrees 2–5
- Evaluate models using **MSE** and **R² Score**
- Visualize regression curves and compare model performance

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## 📊 Evaluation Metrics

- **Mean Squared Error (MSE)** – Lower is better
- **R² Score** – Higher is better

## 📈 Results

The project compares Linear Regression with Polynomial Regression models of different degrees to identify the model that provides the best prediction performance for MPG.
